Arborun MVP 实施计划
├─ 目标
│  └─ 交付可编辑执行树、实时状态、条件决策、受限子 Agent 与可追溯产物的本地桌面 MVP。
├─ 实现
│  ├─ src/shared：类型契约、节点模型与演示资料。
│  ├─ src/harness：持久化执行状态、审批版本、暂停取消、重试、受限模型工具循环。
│  ├─ src/desktop：Electron 主进程、preload、独立运行进程、文件导入导出与模型凭据。
│  └─ src/renderer：树编辑、运行详情、决策、产物和模型配置。
├─ 验证
│  ├─ pnpm test：依赖、版本失效、越界工具、决策、恢复与子 Agent 验收。
│  ├─ pnpm typecheck && pnpm build：前后端类型和生产构建。
│  ├─ 桌面端：演示运行、编辑、暂停、人工选择、产物导出与重启恢复。
│  └─ pnpm package:mac：当前 Mac 的未签名本地试用包；Windows/Linux 另行实际验收。
└─ 交付
   ├─ 所有新 Markdown 文档使用树形结构。
   ├─ 演示执行与真实模型执行明确区分；无远端模型凭据时不宣称真实模型已验收。
   └─ 本轮本地实现，不创建发布、不推送、不选择许可证。
